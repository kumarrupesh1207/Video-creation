# VEER canon (fed to research prompts for any chapter the user has not written)
- Setting: Navkashi, a neon river city built on forgotten temples. Near-future Earth, the Seventh Cycle; the Veil (Avaran) over humanity's memory is cracking.
- Scriptures are fictional texts (the Smriti Sutras) inspired by the world's sacred writings; never call real scriptures "memory files".
- Respect charter (hard rules): Hindu Gods are saviours of the First Age, never villains, never mocked, never shown fighting; shown only as silhouettes,
  symbols, weapons and legend. No religion is hurt or ranked; other cultures' gods are "echoes". No prophets are depicted.
- Power = recalling past lives; every recall erases one present memory (Vinimay). Veer is never claimed to be the prophesied saviour.
