# YouTube SEO: follow the official guidelines, keep the data in the series pack

**Problem:** the first metadata had keyword lists in prose ("Keywords: echoes, the, aether", "Perfect if you like ..."), duplicated hashtags and AI lines, stop-words as tags. Rules now come from `docs/research/YOUTUBE_SEO.md`.
**Fix (`aurora/publish/seo.py`):** description = hook + ONE main keyword (lines 1-2), a unique 2-3 sentence body from THIS part's events (narration/beat, via Gemini or the template), <= 2 short boilerplate lines (next part, playlist), exactly ONE AI-disclosure line, then exactly 3 hashtags (series first). 5-10 tags: series name, its misspellings, curated niche phrases. Only generic genre phrases may come from competitor research, never another show's name. Upload fields: categoryId 1, defaultLanguage/defaultAudioLanguage en. The series playlist is made public when a public video joins; if the API refuses, the video is still added and the daily report flags it.
**Content, not code:** `stories/<slug>/series.yaml` carries `hashtag`, `main_keyword`, `seo_hashtags`, `seo_keywords`, `seo_misspellings`; a new series needs no code. Regenerate a not-yet-uploaded item with `python -m aurora.autopilot reseo <id> [--dry-run]`. Already uploaded videos are never edited automatically.
