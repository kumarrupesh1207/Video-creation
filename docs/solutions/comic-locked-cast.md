# Comic characters drifted between stories -> locked cast per channel

Problem: every new story/reel invented a new look for its hero; the series state only kept characters for the current story.
Fix: `assets/characters/<channel>/<name>.json` is the permanent cast (name, role, fixed description, distinguishing marks, personality, voice notes, 1-3 reference images). `aurora/cast.py` loads it; with `comic.cast_lock: true` (config) `research_comic` (1) puts a LOCKED CAST block with the verbatim descriptions into the Gemini prompt (first member = protagonist of every story), (2) forces the returned character sheet back to the locked name + description if the model changed it (`merge_cast`), (3) in the no-key fallback builds the sheet and panels from the cast. Every panel image prompt therefore embeds the locked description verbatim (`panel_prompt`; keep locked descriptions short, <= ~200 chars, or `_cut` would shorten them to fit NIM's 800-char prompt limit). After a successful render, characters that appeared in panels but are not in the cast are saved (`save_new_members`: description from the sheet, first panel image as reference); locked members are never overwritten. If NIM fails and ComfyUI has to draw the panels, the protagonist's reference image is the IP-Adapter reference.
Seeded 2026-10-23 with Kaelen from "Echoes of the Aether" (`scripts/lock_cast.py <sidecar> <channel>`); the story's guardian had no designed look, so it is not locked yet and will be saved when it first appears in a sheet.
How to recognise drift: a hero with different hair/eyes/cloak in a new reel; check the sidecar `cast` field (`locked`, `added`) and tests/test_cast.py.
